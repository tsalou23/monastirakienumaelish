## 2. HERO SECTION — THE METRO TRAIN

This is the most important part of the entire experience.

Use my provided video as the main reference for the train animation.

Create an immersive, full-screen hero section featuring a metro train approaching the viewer.

**Scroll interaction:**
- When the user scrolls DOWN, the train should move towards the viewer, creating the illusion that it is approaching them.
- As the user continues scrolling, the train should transition through the scene and reveal the next section.
- When the user scrolls UP, the train should reverse its movement and move away from the viewer.
- The animation must be directly tied to scroll progress, not simply autoplay.
- Make the transition feel cinematic, smooth, and realistic.

Use GSAP ScrollTrigger or an equivalent scroll-driven animation technique.

Add minimal typography and branding over the hero, inspired by Athens and Tokyo metro signage.

The hero should immediately communicate the identity of the brand and create a memorable first impression.

## 3. INTERACTIVE CLOTHING RAIL — PRODUCT DISCOVERY

After the train section, introduce a horizontal clothing rail.

Imagine clothing pieces displayed along a metro-style rail, like garments hanging in a futuristic underground fashion showroom.

**Interactions:**
- Display several clothing items hanging next to each other.
- On hover, each garment smoothly rotates or transitions from its angled/side view into a front-facing view.
- On mouse leave, it returns to its original position.
- Clicking a garment opens an interactive product detail experience.

**Product detail interaction:**

When a user clicks on a garment:
- Open a large, immersive product overlay or expanded product view.
- The product image should become significantly larger.
- Use a zoomed-in, atmospheric background with the garment as the focus.
- Display product name, price, and a short description.
- Include available sizes (XS, S, M, L, XL).
- Allow the user to select a size.
- Include an ADD TO CART button.
- Include a clear close/back interaction.

Make this experience feel like opening a fashion editorial rather than a standard product page.

The clothing rail should be one of the signature interactive elements of the website.
